# Skill: AI 视频创作工作室 v2

一站式剧本→AI视频工作流。内置质检+迭代+自动修复。

---

## 工作流

```
剧本分析 → 角色锁定 → 镜头拆解 → 提示词生成 → 质检 → 修复/通过 → 表情注入 → 导出
              ↑_______________________________________________|
                    质检不通过 → 自动修复 → 重新质检 (最多3轮)
```

---

## 质检规则 (每步强制执行)

### 角色质检 (Step 2 完成后)
- [ ] 每个角色有唯一 ID
- [ ] 外貌描述≥50字
- [ ] 含独特识别特征(疤痕/痣/发型/配饰)
- [ ] 负面提示词不为空
- [ ] 同项目角色间外貌无混淆(交叉检查)

### 镜头拆解质检 (Step 3 完成后)
- [ ] 每镜头有唯一编号
- [ ] 景别和运镜明确标注
- [ ] 角色引用使用 [CHAR_XX] 格式
- [ ] 场景引用使用 SCENE_XX 格式
- [ ] 连续镜头景别不重复≥3次(避免单调)
- [ ] 对话镜头≥15秒时已切分

### 提示词质检 (Step 4 完成后) — 每镜头评分
```
得分公式: 完整性×0.3 + 一致性×0.3 + 可执行性×0.2 + 简洁性×0.2

完整性 (0-10): 角色/场景/动作/光线/镜头运动/时长/情绪 7项全有=10分
一致性 (0-10): 角色外貌与锁定档案一致=10分，偏差扣分
可执行性(0-10): 目标AI工具能否直接使用=10分，需手动改=扣分
简洁性 (0-10): ≤300词=10分，300-500=7分，>500=4分

总分≥7: 通过
总分5-7: 警告标记，建议优化
总分<5: 强制重新生成
```

---

## 自动修复规则

质检不通过时，按以下顺序自动修复：

1. **完整性不足** → 补全缺失要素(角色/场景/光线/镜头运动)
2. **一致性偏差** → 用锁定档案替换外貌描述
3. **景别单调** → 交替插入不同景别
4. **简洁性差** → 压缩冗余修饰词
5. **角色混淆** → 全量替换为 [CHAR_XX] 引用

修复后重新质检。最多迭代 3 轮，3 轮后标记 [需人工审核]。

## Step 2: 角色锁定

### 模板
```
【CHAR_XX】名称 v1.0
外貌: [≥50字，含面部/体型/肤色/发型的精确描述]
服装: [默认+备选]
关键特征: [2-3个独特识别点]
参考提示词: "[英文AI生成提示词]"
负面提示词: "[排除项]"
```

### 锁定后规则
- 所有镜头用 `[CHAR_XX]` 引用
- 修改=新版本号 `v1.1`
- 跨镜头外貌一致=强制要求

### 质检完成后才能进入 Step 3

---

## Step 3: 镜头拆解

### 拆解规则
- 动作变化→新镜头
- 情绪转折→新镜头
- 场景切换→新镜头
- 对话>15秒→切镜头
- 连续镜头景别不超过3次重复

### 景别: EWS大远景 WS全景 MS中景 CU近景 ECU特写
### 运镜: Static固定 Push推 Pull拉 Pan摇 Tracking跟 Handheld手持

### 输出格式
```
【SHOT_001】 5s | MS | Static
[CHAR_01] | SCENE_01
内容: [描述]
情绪: [标签]
```

## Step 4: 提示词生成

### 模板
```
[SHOT_XXX] {duration}s | {shotType} | {cameraMove}
{scene_id} interior/exterior. {time_of_day}. {action description}. 
{lighting quality}. {mood}. {camera notes}. {quality tags}.
--char [CHAR_XX]
--scene {scene_id}
```

### 要素清单 (7项必含)
[x] 角色引用 [CHAR_XX]
[x] 场景引用 SCENE_XX
[x] 动作描述
[x] 光线/色彩
[x] 镜头运动
[x] 时长
[x] 风格标签(photorealistic/cinematic/8k等)

### 工具适配
Runway(200-400词) / Pika(100-200词) / Kling(150-300中文友好) / Sora(300-500详细) / Luma(100-250)

## Step 5: 自动质检

每镜头生成后立即执行，不合格自动修复。

伪代码:
```
for each shot:
  score = evaluate(shot)
  round = 0
  while score < 7 and round < 3:
    shot = auto_fix(shot, issues)
    score = evaluate(shot)
    round += 1
  if score < 7: mark "[需人工审核]"
  else: mark "[已通过]"
```

输出质检报告:
```markdown
## 质检报告
- 总镜头: 42 | 通过: 38 | 警告: 3 | 需审核: 1
- 平均分: 8.2/10
- 主要问题: 镜头12景别重复, 镜头25完整性不足
```

## Step 6: 表情注入 (对话镜头)

### 标点→表情+语气+语速
| 标点 | AU | 强度 | 视线 | 语速 | 音量 |
|------|-----|------|------|------|------|
| ， | AU1+2 | 0.3 | FOCUS | 1.0x | 0dB |
| 。 | AU1+2回落 | 0.15 | FOCUS | 0.9x | -2dB |
| ？ | AU1+2+AU5 | 0.75 | EMPHASIS | 1.1x | +2dB |
| ！ | AU20+AU5+AU12 | 0.85 | EMPHASIS | 1.2x | +3dB |
| … | AU1+2 | 0.4 | AVOID | 0.5x | -4dB |
| ； | AU1+2+AU4 | 0.55 | SCAN | 1.0x | 0dB |

视线: FOCUS→EMPHASIS→FOCUS, FOCUS→AVOID→FOCUS, FOCUS→SCAN→FOCUS

### 注入格式
```
[SHOT_042] 5s | CU | Push in | Expression
[CHAR_02] speaking: "对话文本"
Pacing: 0.5x(…)→1.1x(？)
Gaze: AVOID(…0.8s)→FOCUS(0.3s)→EMPHASIS(？0.5s)→FOCUS
```
