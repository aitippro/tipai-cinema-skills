# Skill: AI 导演分镜引擎

将剧本/小说拆解为可直接输入 AI 视频生成工具的分镜提示词。适用于动态漫画、AI 短剧、虚拟制片。

## 工作流程

```
用户上传剧本/小说
  ↓
1. 剧本分析 (角色、场景、情绪、节奏)
  ↓
2. 镜头拆解 (每段→若干镜头)
  ↓
3. 生成分镜提示词 (含角色描述、镜头运动、氛围)
  ↓
4. 连续性与一致性检查
```

---

## 第一步：剧本分析

阅读用户上传的文本，提取：

### 角色信息
- 角色名、外貌特征、服装、年龄
- 性格标签(1-3 词)
- 主要情感弧线

### 场景信息
- 场景名/编号、地点描述
- 时间(白天/夜晚/黄昏/室内)
- 光线特征(自然光/暖光/冷光/逆光)

### 叙事分析
- 整体节奏(快/慢/混合)
- 情感曲线(开心→悲伤→紧张→释然)
- 关键转折点

### 视觉风格
- 色彩基调(暖色调/冷色调/高饱和/低饱和)
- 画面风格(写实/赛博朋克/水墨/日系/美式)
- 宽高比建议(16:9 通用 / 21:9 电影 / 9:16 竖屏)

### 输出格式
```markdown
## 剧本分析: [剧本名]

### 角色
- **张三**: 男, 28岁, 黑色风衣, 短发, 消瘦 — 忧郁、内敛
- **李四**: 女, 25岁, 白色连衣裙, 长发 — 活泼、天真

### 场景
- **场景1**: 咖啡馆 — 下午, 暖光, 木色调
- **场景2**: 天台 — 黄昏, 金色逆光, 开阔

### 情感曲线
开场(平静) → 相遇(微甜) → 冲突(紧张) → 告别(悲伤) → 尾声(温暖)

### 视觉风格
暖色调为主, 日系清新风格, 16:9
```

---

## 第二步：镜头拆解

将剧本按事件节点拆为镜头序列。每镜头包含：

### 镜头模板
```
【镜头 X】时长 Y 秒 | 景别 | 运镜

**画面**: [一句话描述画面核心内容]
**角色**: [出场角色及动作]
**对话**: [如有的话]
**光线**: [光线描述]
**情绪**: [此镜头传达的情绪]
**转场**: [切/淡入/淡出/匹配剪辑]
```

### 景别参考
| 景别 | 英文 | 适用场景 |
|------|------|---------|
| 大远景 | EWS | 环境建立 |
| 全景 | WS | 场景+人物全身 |
| 中景 | MS | 人物膝盖以上 |
| 近景 | CU | 人物胸部以上 |
| 特写 | ECU | 面部/物品细节 |

### 运镜参考
| 运镜 | 英文 | 效果 |
|------|------|------|
| 固定 | Static | 稳定观察 |
| 推 | Push in | 关注聚焦 |
| 拉 | Pull out | 揭示环境 |
| 摇 | Pan | 场景扫描 |
| 跟 | Tracking | 跟随运动 |
| 升/降 | Crane | 空间变化 |
| 手持 | Handheld | 紧张/真实感 |

### 拆解规则
- 动作变化 → 新镜头
- 情绪转折 → 新镜头
- 场景切换 → 新镜头
- 对话超过 15 秒 → 切镜头(避免单调)
- 一段长对话 → 至少 2-3 个不同景别交替

---

## 第三步：生成 AI 视频提示词

每个镜头输出两种格式：

### 格式 A: 分镜描述 (给 Midjourney / SD 生成关键帧)
```markdown
**镜头 3 [5秒 | 近景 | 推镜]**
Zhang San close-up portrait, pushing in slowly. Dim cafe lighting, warm amber tones, soft bokeh background. Eyes welling up with restrained emotion, jaw slightly clenched. Shallow depth of field, 85mm lens. Photorealistic, cinematic color grading, 8k quality.
--ar 16:9 --style raw
```

### 格式 B: 视频生成提示词 (给 Runway / Pika / Kling / Sora)
```markdown
**镜头 3 [5秒 | 推镜]**
A slow push-in shot. Man in black coat sitting at wooden cafe table. Warm amber light from window. He slowly raises his eyes, micro-expression of sadness flickering across his face. Hand gripping coffee cup tightens. Dust particles floating in light beam. Slight camera shake (natural handheld feel). Photorealistic, 24fps film look.
```

### 提示词要素清单
每个视频提示词必须包含:
- [x] 主体描述 (谁/什么)
- [x] 动作描述 (干什么/怎么动)
- [x] 光线/色彩 (氛围)
- [x] 镜头运动 (推/拉/摇/跟/固定)
- [x] 时长 (X 秒)
- [x] 情绪/氛围
- [x] 风格词 (photorealistic / cinematic / anime / ink-wash 等)
- [x] 分辨率/质量标签

---

## 第四步：连续性检查

生成所有镜头后，检查：

1. **角色一致性**: 同一角色的外貌描述跨镜头一致
2. **空间连续性**: 同一场景的方位关系一致
3. **光线连续性**: 同场景光线方向一致
4. **情绪连续性**: 情感变化有过渡，不突兀
5. **节奏**: 镜头时长分配合理(紧张场景短镜头 1-3s，抒情场景长镜头 5-8s)

输出连续性报告：
```markdown
## 连续性检查
✅ 角色一致: 张三所有镜头均为"黑色风衣+短发"
✅ 光线一致: 场景1 所有镜头暖光方向统一
⚠ 镜头5-6 情绪跳跃: 建议插入过渡镜头
```

---

## 输出模板

最终交付结构：
```
剧本分析报告
  ├── 角色档案
  ├── 场景清单
  ├── 情感曲线
  └── 视觉风格
镜头拆解表
  ├── 镜头 1-N (含时长/景别/运镜)
  └── 总时长统计
AI 提示词
  ├── 每镜头: 关键帧提示词 + 视频提示词
  └── 推荐工具标注
连续性检查报告
```

## 参考参数

| AI 工具 | 推荐 prompt 长度 | 最佳时长 | 备注 |
|---------|-----------------|---------|------|
| Runway Gen-3 | 200-400 词 | 4-10s | 需指定 motion/camera |
| Pika Labs | 100-200 词 | 2-5s | 支持 image-to-video |
| Kling | 150-300 词 | 5-10s | 中文 prompt 友好 |
| Sora | 300-500 词 | 10-60s | 需要详细场景描述 |
| Luma Dream | 100-250 词 | 2-5s | 风格迁移强 |
| 即梦 Jimeng | 50-150 词 | 2-5s | 字节系 |

## 动态漫特殊处理

如果用户目标是动态漫画：
- 风格词: `anime style, manga shading, cel animation, clean lines`
- 景别偏向: 中景/近景为主(漫画格)
- 运动: 有限动画(2-3 层 parallax)、镜头平移为主
- 帧率: 12fps(逐帧感) 或 24fps(流畅)
- 色彩: 平涂为主，少用渐变
