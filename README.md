# TipAi Cinema Skills

源自 [TipAi](https://github.com/aitippro/TipAi) 桌面版多模态引擎迁移的独立 AI Skill 模块集。

由 TipAi 的提示词工作流、TPEMA 表情引擎、长视频创作管线提炼为可独立加载的 `.md` Skill 文件。Agent 加载后直接用自身 AI 能力执行，零代码、零依赖。

---

## Skills

| Skill | 说明 |
|-------|------|
| **[ai-video-studio.md](skills/ai-video-studio.md)** | 一站式创作工作流（推荐） |
| [director-storyboard.md](skills/director-storyboard.md) | 导演分镜 |
| [prompt-lifecycle.md](skills/prompt-lifecycle.md) | 提示词生命周期 |
| [tpema-expression.md](skills/tpema-expression.md) | 表情+语气+语速 |

## 来源

本仓库 Skill 由 **TipAi v1.0** 桌面应用的多模态引擎、TPEMA 表情控制系统、提示词生命周期管理等核心功能提炼而成。

> TipAi 是本地优先的全链路 AI 提示词工程桌面工具（React + Electron + Rust），详见 [TipAi 主仓库](https://github.com/aitippro/TipAi)。
