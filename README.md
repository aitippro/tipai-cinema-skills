# TipAi Skills

可加载的 AI Skill 定义文件。Agent 加载后直接用自身 AI 能力执行。

## Skills

| Skill | 说明 |
|-------|------|
| [director-storyboard.md](skills/director-storyboard.md) | AI 导演分镜 — 剧本→分镜提示词(动态漫/AI短剧) |
| [tpema-expression.md](skills/tpema-expression.md) | TPEMA 表情引擎 — 标点→FACS AU+语气+语速+视线 |
| [multimodal-prompt.md](skills/multimodal-prompt.md) | 多模态提示词 — 文生图/图生文/视频分镜 |

## 使用

加载 Skill 到你的 Agent 中，Agent 自动按 Skill 指令生成专业提示词。用户无需 API Key。
